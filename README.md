# 야생튜브

배우는 주제를 퀘스트처럼 위에서 아래로 이어 가는 개인 학습 화면. 내용과 노트는 비공개 저장소(키 필요)에 있고, 이 저장소에는 화면 코드만 있다.

## 야생 피드 (feed.html)
인스타·유튜브처럼 넘겨 보는 개인 피드. 최근에 물어본 것, 읽을거리·논문, 주제별 시연 영상만 올라온다. 데이터는 같은 비공개 백엔드(키 필요)에서 온다.

## 크롬 확장 (extension/)
인스타그램·유튜브 홈, 릴스, 쇼츠, 탐색을 열면 야생 피드로 보낸다. 게시물·영상·DM 링크는 그대로 열린다. 팝업에서 10분 통과, 끄기.
