1목적과 쓰는 사람

같은 곡을 두 연주로 나란히 듣고, 어디가 왜 다른지 귀로 확인하는 곳이에요.

지금: 사장님. 집에서 폰으로 공부하듯 들어요. 한 손으로 누르고, 악보와 설명을 읽으면서 A와 B를 번갈아 들어요.
나중: 클래식 팬 커뮤니티. 오픈소스처럼 누구나 짝과 비교 페이지를 더해요(JSON만 추가, 화면 코드는 그대로). 처음 온 사람도 설명 없이 상자를 뒤져 판을 꺼낼 수 있어야 해요.

2사용 사례 7개

U1작곡가로 찾아 판을 꺼내고 비교 페이지를 연다.
작곡가 칩 '브람스'→상자가 브람스 판만→꺼내기→비교 페이지 열기
U2연주자 이름으로 찾는다.
검색 '굴드'→걸러진 판 첫 장으로→◀ ▶ 또는 아래 목록→꺼내기
U3A-Z로 상자를 뒤적인다.
글자 'M'→휘리릭 넘어감→다음 ▶ 몇 번→마음에 드는 판 꺼내기
U4내 목록에 담고 나중에 다시 본다.
꺼낸 판→☆ 내 목록→(다음 날) 장르 '내 목록'→담은 판만
U5비교 페이지에서 파트마다 A 듣고 B 듣는다(턴테이블 2대).
단계 카드 읽기→A 듣기→A 판 회전→B 듣기→B 판 회전, A 정지→들은 뒤 펼치기
U6같은 구간을 A와 B로 빠르게 번갈아 듣는다(전환).
A 재생 중→A↔B 바꾸기→B가 같은 구간에서→다시 바꾸기
U7비교 페이지가 없는 짝은 유튜브에서 찾거나 요청한다.
꺼내기→A 유튜브에서 찾기/B 유튜브에서 찾기→비교 페이지 요청

7스타일 원칙

판과 표지는 고풍스럽게. 노란 카르투슈 라벨, 이중 장식 테두리, 세리프 대문자(Cormorant Garamond, Noto Serif KR). 표지 아래 그림은 항목마다 정해지는 추상 무늬. 실제 음반 사진·회사 로고는 쓰지 않아요.
조작 요소는 리퀴드 글라스. 반투명 패널, 블러와 채도 올림, 얇은 밝은 테두리, 안쪽 하이라이트, 떠 있는 그림자. 눌리면 살짝 들어가고, 손을 올리면 빛이 스쳐요. 블러는 조작 바·칩 묶음·상세 카드·고정 영역에만 쓰고 판에는 쓰지 않아요.
색 규칙. A 늘 남색 B 늘 적갈색, A가 먼저·왼쪽. 배경은 크림·나무·금색 안에서 부드러운 그라데이션과 은은한 빛 번짐.
아이콘과 글자 함께. 이전, 다음, 재생, 일시정지, 별, 유튜브 찾기, 열기는 아이콘 옆에 글자를 늘 보여요. 숨은 제스처만으로 되는 기능은 없어요.
움직임 시간. 넘기기 0.6초(살짝 튕기는 곡선), 휘리릭 한 장 0.07초, 꺼내기 0.6초(판이 돌며 나옴), 톤암 0.8초, 판 회전 33⅓rpm(한 바퀴 1.8초), 정지 감속 약 1.5초.
움직임 줄이기 설정이면. 넘기기·꺼내기는 바로 바뀌고, 판 회전 대신 '재생 중' 글자와 불빛만, 스치는 빛과 배경 빛 움직임은 끔.
글자. 본문 16px 이상, 유리 위 본문 대비 4.5:1 이상. 비교 페이지 본문 카드는 유리를 약하게 해서 읽기를 먼저.

9정해 주실 것

1. 턴테이블 영역: (가) / (나) / (다) 중 하나추천 (나)

이유: 영상이 늘 화면에 보여서 규정 걱정 없이 오래 공부하듯 들을 수 있어요. 판이 작아지는 대신, 바꾸기 버튼을 지금 재생 줄에 넣어 (다)의 장점도 가져와요.

2. U6 A↔B 바꾸기를 이번에 넣을까요추천: 넣기(구간 처음부터)

이유: 번갈아 듣기가 이 페이지의 핵심이라 버튼 하나로 바로 바꾸는 효과가 커요. 같은 마디로 정확히 옮기는 전환은 비교 페이지에 마디 시간표를 더한 뒤 다음에 넣어요.
